What is QuickBoard?

QuickBoard is a lightweight Jira dashboard that aggregates tasks from multiple projects and sprints into a single, unified view. Instead of switching between boards, QuickBoard pulls everything into one place so you can filter, sort, and focus on what matters — without ever leaving your browser.

  • ✓ Aggregate issues across multiple Jira projects and active sprints
  • ✓ Switch between a filterable table view and a kanban board
  • ✓ Filter by status, assignee, priority, and more in real time
  • ✓ No backend account required — your credentials stay on your device

How it works

  1. 1

    Enter your credentials

    Provide your Atlassian email, a personal API token, and your Jira base URL (e.g. https://yoursite.atlassian.net). These are saved only in your browser's localStorage.

  2. 2

    QuickBoard connects to Jira

    Requests are sent through a local proxy to the Jira REST API. QuickBoard fetches your active sprints and all issues across the projects you have access to.

  3. 3

    Tasks appear in your dashboard

    All issues are loaded into a unified table and kanban board. Use the filter bar to narrow down by project, sprint, status, assignee, or priority — and switch views with one click.

Getting your API token

QuickBoard authenticates with the Jira REST API using a personal API token linked to your Atlassian account. Follow these steps to create one:

  1. 01 Open id.atlassian.com/manage-profile/security/api-tokens and sign in with your Atlassian account.
  2. 02 Click Create API token, give it a descriptive label (e.g. "QuickBoard"), and confirm.
  3. 03 Copy the generated token — it is shown only once. Paste it into the API Token field on the login page.
Tip: Your API token has the same permissions as your Atlassian account. Only create tokens for tools you trust, and revoke them at any time from the same page.

Privacy

QuickBoard is built with a local-first approach. Your credentials are never transmitted to any server other than Jira itself.

  • ■ Your email, API token, and base URL are stored exclusively in your browser's localStorage. They never leave your device in any other way.
  • ■ All calls to the Jira API are routed through a local proxy running on your machine, not a remote QuickBoard server.
  • ■ QuickBoard has no analytics, telemetry, or external dependencies beyond the Jira API.
  • ■ You can clear your credentials at any time by logging out, which removes all entries from localStorage.
